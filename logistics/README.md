## 2. 수리모형 (코드: `solve_cfl.py`, `solve_cpsat.py`)

- 집합: I(600 권역), J(160 후보), K = {상온, 냉장}
- 변수: Xⱼ ∈ {0,1}, Yᵢⱼᵏ ∈ {0,1}
- 목적: min Σⱼ fⱼXⱼ + Σₖ τᵏ Σᵢ Σⱼ hᵢᵏ dᵢⱼ Yᵢⱼᵏ  (dᵢⱼ = 격자 단위 직선거리)
- 제약
  - Σⱼ Yᵢⱼᵏ = 1 ∀i,k (품목별 단일할당)
  - Σᵢ Σₖ vᵏ hᵢᵏ Yᵢⱼᵏ ≤ Kⱼ Xⱼ ∀j (v¹=1, v²=2.5, 두 품목이 용량 공유)
  - Yᵢⱼᵏ ≤ Xⱼ (LP 완화 강화)
  - Yᵢⱼ² ≤ aⱼ² → 코드에서는 냉장 설비가 없는 j에 대해 Yᵢⱼ² 변수를 아예 만들지 않음
- 규모: 이진변수 160 + 600×160 + 600×31 = 114,760개, 제약 약 115,000개

## 3. 풀이 과정

| 단계 | 방법 | 결과 |
|---|---|---|
| ① 전체 MIP | HiGHS, 20분 | 해 98,395 / 하한 93,402 (갭 5.1%) |
| ② LP 완화 | Y≤X 포함 강한 LP | 93,140 (거의 정수: 60곳 중 대부분 X=1) |
| ③ 후보 축소 MIP | LP에서 X>0인 60곳만 | 95,453 |
| ④ 국소탐색 | 이동·교환 + 센터 열기/닫기 | 94,352 |
| ⑤ MIP 기반 LNS | 일부 지역만 풀고 나머지 고정 | 94,116 |
| ⑥ CP-SAT 전체 모형 | OR-Tools, ④⑤ 해를 힌트로 | 94,058 |
| ⑦ CP-SAT LNS | 작은 이웃을 반복해서 최적화 | 94,022.92 |
| ⑧ 추가 20분 | LNS 3개 병렬 (작은 이웃·많은 반복이 가장 효과적) + HiGHS 초기해 주입 | **93,990.62** |
| (참고) 분할배정 MIP | Y를 연속변수로 (단일할당 해제) | 93,460 (최적) |

- 하한: HiGHS 전체 모형의 dual bound ≈ 93,420. 분할 배정을 허용한 최적값 93,460도 단일할당 문제의 하한 역할을 합니다
  (완화 문제이므로). 따라서 **진짜 최적값은 93,460 이상이고, 우리 해는 최적보다 최대 0.6%(≈531) 비쌉니다.**
- 참고: 리더보드 1위는 93,607로, 우리 해보다 약 0.41% 낮습니다. 최적성까지 증명하려면 Gurobi 같은 상용 솔버로
  더 오래 풀거나 branch-and-price가 필요합니다.

## 4. 「생각해 볼 것」 답

1. **고정비 싼 후보만 고르면?** fⱼ가 가장 싼 17곳의 용량 합은 3,014뿐입니다(필요 36,642). 싼 순서로 계속 열면
   **109곳**을 열어야 용량이 채워지고 고정비만 74,397이 됩니다. 기준은 f가 아니라 **fⱼ/Kⱼ(용량 단위당 고정비)** 여야 하며,
   이 기준으로는 49곳·고정비 53,357이면 용량을 채웁니다.
2. **냉장 후보만 열면?** 냉장 31곳을 모두 열어도 용량은 31,015로, 필요한 36,642보다 5,627 부족합니다 → **운송비 이전에 실행불가**입니다.
   냉장 부피(7,194×2.5 = 17,985)는 냉장 설비 용량의 58%를 차지합니다. 우리 해에서는 냉장 센터 26곳이 냉장 물량을 받고,
   냉장 설비 없는 f/K가 낮은 센터 27곳(C33, C49, C99, C102, C107, C116, C118, C126 …)이 나머지 상온 물량을 받습니다.
3. **물동량 vs 부피**: 예를 들어 D346(199/138)은 물동량 합이 337이지만 부피로는 544입니다. 우리 해의 평균 가동률은 99.3%로,
   센터 대부분이 부피 기준으로 꽉 차 있습니다.
4. **상온·냉장 분리 배정**: 최적해에서 **401개 권역**이 두 품목을 서로 다른 센터로 보냅니다. 냉장은 단가가 2.5배라
   가까운 냉장 센터로 가고, 상온은 f/K가 싼 상온 전용 센터로 빠집니다.
5. **가장 큰 권역**: 가장 큰 단일 권역(D346)은 부피 544로 전체의 1.5%에 불과합니다. 문구의 "약 34%"는 광역 **R1(36.8%, 부피 13,484)**을
   가리키는 것으로 보입니다. 가장 큰 후보 하나(2,230)로는 받을 수 없고, R1 안의 후보 용량(19,890)도 f/K가 비쌉니다.
   그래서 우리 해에서는 R1 수요의 상당 부분이 R3·R5 센터로 넘어갑니다(R1→R3 98건, R1→R5 72건 배정).
6. **손풀이 vs 솔버** (`hand_heuristic.py`): 권역마다 f/K가 싼 냉장 센터 → 상온 센터 순으로 110%를 여는 손풀이는 58곳을 엽니다.
   - 가장 가까운 센터로 배정하면 105,452이지만 **21곳이 용량 초과 → 실행불가**
   - 용량을 지키며 탐욕 배정하면 **114,580 (우리 해 대비 +22%)**

   과소평가한 제약은 **용량 제약, 특히 냉장 2.5배 부피 환산과 두 품목이 용량을 공유한다는 점**입니다. 손풀이는 물동량 기준으로
   "여유 있다"고 판단해 최근접 배정을 하다가 냉장 센터가 넘치고, 이를 메우려 센터를 더 열거나(고정비↑) 먼 곳으로 보내게 됩니다(운송비↑).
   또 **단일할당 + 용량 = GAP(NP-hard)** 이므로 개설 집합이 같아도 배정 방법에 따라 비용이 수백 이상 차이 납니다
   (분할 허용 93,460 vs 단일할당 ≥ 93,6xx).
